### Link 1

- **Title:** Dynamic group rule: memberOf
- **URL:** https://learn.microsoft.com/en-us/entra/identity/users/groups-dynamic-rule-member-of
- **Description:** The memberOf operator in Entra dynamic group rules stops on 3 November, so check your rules. It targets members based on their membership of another group.


### Link 2

- **Title:** Create an agent blueprint
- **URL:** https://learn.microsoft.com/en-us/entra/agent-id/create-blueprint
- **Description:** Agent ID does not require admin consent, and blueprint creation is open to default users unless switched off. The blueprint is the template from which agent identities are created.


### Link 3

- **Title:** Continuous access evaluation (CAE)
- **URL:** https://learn.microsoft.com/en-us/entra/global-secure-access/concept-universal-continuous-access-evaluation
- **Description:** CAE gains additional device-risk signals. It re-checks access when conditions change, such as device risk, instead of waiting for the token to expire.


### Link 4

- **Title:** AI agent runtime protection
- **URL:** https://learn.microsoft.com/en-us/defender-endpoint/configure-ai-agent-runtime-protection
- **Description:** Defender for Endpoint protection for AI agents running on endpoints, now also exposed in Intune through an Endpoint Security template.


### Link 5
